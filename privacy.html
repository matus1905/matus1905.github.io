Privacy Policy

Last updated: November 17, 2026

yt-uploader ("the app") is a private tool used only by its owner to upload their own gameplay videos to their own YouTube channel. It is not offered to other users.

What data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos and to set their title, description, tags, thumbnail, privacy status and publishing time on the owner's channel.

How the data is stored

The OAuth access token is stored only on the owner's own computer. The app does not have a server and does not send any data to anyone other than Google / YouTube. No data is sold, shared or used for advertising.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the token file on the owner's computer also removes the app's access.
